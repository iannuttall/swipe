# Swipe operator docs

Use these guides when setting up or changing Swipe infrastructure.

- [Email setup](email-setup.md): Cloudflare Email Routing, Mailroom, Gmail,
  Amazon SES, IAM, SNS, DNS, and the public webhook.
- [Email tests and maintenance](email-operations.md): acceptance tests,
  credential rotation, webhook rotation, and troubleshooting.
- [Subscriber confirmation](subscriber-confirmation.md): Turnstile, double
  opt-in, the Ian's List migration batch, reports, and cleanup.

Do not paste secret values into these files, terminal output, issues, or
screenshots. Commands use placeholders where a value is private.
