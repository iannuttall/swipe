<Header name="This week's Swipe" />

AI gets much more useful when there are practical examples of how you can use tools and workflows to create, keep, edit, or share things. This week's tools turn rough ideas into drawings, charts, web pages, and notes.

We also found four agent workflows worth stealing. They help you improve a brief before work starts, plan AI video cheaply, ground copy in customer research, and set a quality bar for agent-built software.

<Item id="tldraw-offline" title="tldraw offline" url="https://offline.tldraw.com/" new="true">
Sketch, build, and present.

<Like>
Start with a rough sketch, then ask an agent to turn the same page into a dashboard, presentation, or small app. You can keep changing it yourself after the agent has finished.
</Like>

<Dislike>
A shared tldraw file can include code. Only open files from people you trust, just as you would with an app or script.
</Dislike>
</Item>

<Item id="flint" title="Flint" url="https://microsoft.github.io/flint-chart/" new="true">
Turn data into charts.

<Like>
Give Flint a small table and describe the chart you need. We used the same setup to make two different chart styles, which is handy when a client wants the numbers presented another way.
</Like>

<Dislike>
It is still early and can ignore options it does not understand. Check the chart against your source data before sharing it.
</Dislike>
</Item>

<Item id="here-now" title="Here.now" url="https://here.now/" new="true">
Free instant web hosting for agents.

<Like>
Give an agent a report, mockup, or small web page and Here.now gives you a link to share. We used it without creating an account. This beats asking a client to download code just to see a quick demo.
</Like>

<Dislike>
Free links are public and disappear after 24 hours. They are fine for throwaway demos, but a bad choice for private or permanent work.
</Dislike>
</Item>

<Item id="marka-md" title="marka.md" url="https://github.com/mattenarle10/markamd" new="true">
Local-first Markdown editor.

<Like>
Write your notes in Markdown, pick the ones you need, and copy them into ChatGPT, Claude, or another agent. You choose exactly what the agent sees instead of handing over an entire folder.
</Like>

<Dislike>
The token count is only a rough guess. Read everything before copying it because one selected note could contain a password or something private.
</Dislike>
</Item>

<Item id="blindspot-pass" title="Find the blind spots" url="https://github.com/Neeeophytee/finding-unknowns-skills/blob/main/skills/blindspot-pass/SKILL.md" kind="workflow">
Improve the brief before work.

<Like>
Before an agent starts unfamiliar work, ask it to find the landmines, hidden context, examples worth copying, and questions an expert would ask. This skill then rewrites your original brief with those findings included. It is useful when a cheap planning pass could prevent an expensive wrong turn.
</Like>

<Dislike>
It deliberately stops before doing the work. Skip it for small, familiar jobs where the extra pass would only slow you down.
</Dislike>
</Item>

<Item id="video-preflight" title="Storyboard first" url="https://github.com/dawndrain/movie-gen" kind="workflow">
Save money on AI video.

<Like>
Ask your agent to make a rough video from still images and draft voices before generating the final clips. The movie-gen workflow says the preview takes about two minutes. Its draft voice test cost 0.3 credits while the video clip cost about 24, so story, timing, and voice problems stay cheap to fix.
</Like>

<Dislike>
Those costs depend on a changing set of paid tools. A rough preview will not prevent every retake.
</Dislike>
</Item>

<Item id="customer-language" title="Mine customer words" url="https://github.com/Cesarjoquin/Marketing-Skills/blob/main/skills/customer-research/SKILL.md" kind="workflow">
Ground AI copy in research.

<Like>
Give an agent interview transcripts, support tickets, survey answers, or reviews before asking for copy. This skill makes it pull out pains, triggers, desired outcomes, and the exact phrases people use. It also demands at least five independent data points before building a persona, which is a useful brake on made-up marketing.
</Like>

<Dislike>
Online reviews overrepresent people with strong opinions. The agent still needs enough real customer material to separate a useful pattern from one loud complaint.
</Dislike>
</Item>

<Item id="quality-bar" title="Check what the agent built" url="https://x.com/almonk/article/2079461952577802549" kind="workflow">
Keep the quality bar high.

<Like>
AI makes software faster to build. It also makes it faster to pile on bad features and ship bugs. Before publishing anything an agent made, check that it works reliably, stays quiet, sticks to one job, and gets fixed quickly when it breaks. A human still has to test the details and decide what is good enough.
</Like>

<Dislike>
This is a quality standard rather than a step-by-step test. You still have to turn each principle into checks for your own product.
</Dislike>
</Item>
