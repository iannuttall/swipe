### Homebench

- Canonical URL and repository: https://github.com/david-g-3654/homebench
- Type and platforms: Python repository for macOS, Linux, and Windows
- Central job: compare local language models on the user's own machine and tasks.
- Best reader: someone choosing between models served by Ollama, LM Studio, llama.cpp, vLLM, or another local OpenAI-compatible endpoint.
- Supported move: write a five-task JSON pack for one repeated job and compare the failures alongside speed.

## Selected workflows

### Write instructions in Simple English

- Primary source: https://github.com/AminBlg/SimpleEnglish/blob/main/skills/simple-english/SKILL.md
- Whole-source summary: an agent skill adapts Simplified Technical English rules for software documentation, with separate procedural and descriptive modes, a rule catalogue, protected code spans, examples, and a deterministic evaluation method. It explicitly excludes marketing and brand voice.
- Exact move: rewrite one commonly misunderstood troubleshooting section with short sentences, one instruction per sentence, and conditions before commands.
- Safe test: the repository's deterministic linter self-test passed with 12 violations in its bad fixture and none in its clean fixture. The linter documents that it is a comparison aid, not a compliance verdict.
- Limitation: the published benchmark is author-run, covers six Claude models and eight tasks, and the regex linter cannot measure full STE compliance.

### Version the build brief

- Primary source: https://martinfowler.com/articles/structured-prompt-driven/
- Whole-source summary: Structured Prompt-Driven Development treats a detailed prompt as a maintained design artifact that covers requirements, domain knowledge, approach, structure, operations, norms, and safeguards. The article recommends updating it with the code and describes where the method is a poor fit.
- Exact move: ask the agent for a one-page build brief and stop; review its assumptions and forbidden changes before code; update the brief first for a behaviour change.
- Limitation: the author says this adds overhead for hotfixes, exploration, one-off scripts, and visual or creative work. Human judgment remains load-bearing.

### Steer with your expertise

- Primary source: https://www.seangoedecke.com/llms-reward-expertise/
- Whole-source summary: the same model becomes more useful when a domain expert can push back, suggest alternatives, spot odd output, and verify the result. The essay uses coding and mathematics examples and does not claim the model replaces expertise.
- Exact move: run the agent on a familiar task, interrupt weak assumptions, explain a better route, and save the corrections for the next run.
- HN comments largely supported the mechanism while raising the cost of losing the experience needed to steer and review the agent.
- Limitation: this is a practice supported by examples, not a controlled performance study.
